# GG Carriers CRM & Smart Lead Management System

**Enterprise-Grade CRM + Field Management System for Logistics Industry**

Built for GG Carriers - India's Leading Transport & Logistics Company (Est. 1963)

---

## 📋 Overview

A production-ready, scalable SaaS-style CRM + Field Management System (FMS) designed specifically for logistics and transport companies. Built with modern technology stack, featuring AI-powered lead validation, sales pipeline management, and comprehensive field sales tracking.

### Key Features

✅ **Smart Lead Management** - AI-powered duplicate detection & company validation  
✅ **Excel Import with AI Validation** - Bulk import with automatic data enrichment  
✅ **Sales Pipeline Kanban** - Drag & drop lead management  
✅ **Field Sales Tracking** - GPS check-in/out, visit history, route optimization  
✅ **Multi-Role Authentication** - 6 role-based access levels  
✅ **Advanced Analytics** - Real-time dashboards & performance metrics  
✅ **Follow-up Management** - Call, meeting, email & SMS reminders  
✅ **Quotation Module** - Generate & send quotations with email integration  
✅ **Mobile Responsive** - Works seamlessly on desktop, tablet, mobile  
✅ **Production Ready** - Handles 1M+ leads, optimized for scale

## 🏗️ Technology Stack

### Frontend
- **Framework**: Next.js 14 (App Router)
- **UI Library**: React 18 + TypeScript
- **Styling**: Tailwind CSS 3 + ShadCN UI
- **Animations**: Framer Motion
- **State Management**: Zustand
- **Charts**: Recharts
- **Forms**: React Hook Form + Zod

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **ORM**: Prisma
- **Authentication**: JWT + Google OAuth
- **Validation**: Zod

### Database
- **Primary**: PostgreSQL 15+

### Infrastructure
- **Frontend**: Vercel
- **Backend**: Railway
- **Database**: Supabase PostgreSQL
